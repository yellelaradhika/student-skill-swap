​🚀 SkillSwap
​Connect. Swap. Learn. The #1 platform for students to exchange skills—from coding to cooking.
​📌 Project Overview
​SkillSwap was developed during the byteXL Front End Development Hackathon (Feb 2026). It addresses the need for a collaborative student community where knowledge is the primary currency. Instead of paying for courses, students can "swap" their expertise (e.g., Python programming for UI Design).
​✨ Key Features
​Skill Marketplace: A dynamic dashboard to browse available skills.
​Category Filtering: Skills categorized by Tech, Business, Design, Finance, and Art.
​Propose Swap: Interactive buttons for users to initiate a skill exchange.
​Expertise Levels: Clear indicators of user proficiency (Beginner, Intermediate, Expert).
​Responsive UI: A modern dark-themed interface built for seamless navigation.
​🛠️ Tech Stack
​Frontend: React.js
​Styling: CSS3, Bootstrap
​Deployment: GitHub Pages
​Tools: Git, VS Code
